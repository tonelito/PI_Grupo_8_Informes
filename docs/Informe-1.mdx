# Informe 1: Mantenimiento de una computadora

Este informe documenta el proceso de mantenimiento físico realizado a una
computadora portátil: limpieza exterior e interior, extracción de batería,
memoria RAM, dispositivo de almacenamiento, disipador y ventilador, y el
reemplazo de la pasta térmica del procesador. Incluye además las
recomendaciones y advertencias necesarias para realizar este procedimiento de
forma segura, junto con evidencia fotográfica del grupo durante el proceso.

## Trifoliar

Como material de apoyo, se preparó un trifoliar con una guía rápida de
mantenimiento preventivo (limpieza externa, cuidado de batería, ventilación y
mantenimiento de software) pensado para cualquier usuario, sin conocimientos
técnicos avanzados.
