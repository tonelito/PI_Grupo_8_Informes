# Informe 2: Dualboot con Linux Mint y Redes Cableadas e Inalámbricas

Este informe documenta dos procesos. El primero es la instalación de Linux Mint
22.3 Cinnamon en configuración dual-boot junto a Windows, sin desinstalar ni
perder el sistema operativo existente: preparación de Windows, creación de la
USB booteable, reducción de volumen, configuración de BIOS/UEFI, particionado e
instalación, y la configuración posterior. El segundo es la configuración de
redes cableadas e inalámbricas entre distintos sistemas operativos
(Windows – Windows, Linux – Linux y Windows – Linux). Cada proceso incluye su
video tutorial, manual y trifoliar como guía rápida.

## Video 1: Instalación de Linux Mint 22.3

### Trifoliar

Como material de apoyo, se preparó un trifoliar con una guía rápida de
instalación de Linux Mint 22.3 en dual-boot: preparación de Windows (punto de
restauración y desactivación de BitLocker), creación de la USB booteable con
Rufus, reducción de volumen, configuración de BIOS/UEFI, particionado
(`/`, `swap`, `/home`) y configuración posterior. Incluye además una sección de
ayuda con los problemas más frecuentes y su solución.
